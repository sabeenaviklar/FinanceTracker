💸 Personal Finance Visualizer
A modern, full-stack finance tracking app built with Next.js, MongoDB, and Recharts, allowing users to add, view, and visualize their personal transactions and monthly expenses.

🚀 Features
📥 Add income or expense transactions (amount, description, date)

📊 Visualize expenses month-wise using a bar chart

🧾 View transaction history in a table format

🔧 Full-stack with MongoDB backend and RESTful API routes

🛠 Tech Stack
Frontend: Next.js, React

Styling: Tailwind CSS

shadcn/ui – For Beautifully designing the UI components using Tailwind & Radix

Backend: Next.js API Routes

Database: MongoDB with Mongoose
